For instructors

Make a link for your class

Teach a subset of the structures? Uncheck the ones you don't cover, add your class name if you like, and share the link at the bottom of this page. The atlas, quiz, and glossary then show only what you left checked, and your selection follows students through every page.

A link looks like torryscott.github.io/lambda/?on=5777777777x7777773776py. That code spells out exactly which structures are in, so anything added to Lambda later stays out of your link until you make a new one.

Advanced
Only change this if you host your own copy of Lambda.

The link carries two masks. on= has one bit per structure, in a permanent order, set for each one you leave checked; views= does the same for the views. A structure or view added to Lambda after your link was made has no bit in it, so it stays out until you open this page from your link and copy a new one. A link with no masks at all is the plain site and shows everything.

Every structure also has a permanent short code, a view letter and a number, shown at the right of each row. The same structure has a separate code in each view it appears in. Open this page from one of your own links and it starts with that link's selection and class name filled in.
