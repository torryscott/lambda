Pick a class to chart its opens. Copy results link makes a private link for that class's instructor: it opens this page with that class's counts and quiz results, and nothing else.

Quiz results by structure

Answers
Times the structure was asked and answered, for the mode and visitors chosen above. A question counts once, when the student moves on to the next one or leaves the quiz. Only quizzes started with Begin count; a retry of the missed questions does not.
Right
The answer matched the structure's name or one of its accepted synonyms.
Wrong
An answer was submitted and did not match.
Skipped
The student pressed Skip, or submitted an empty answer.
Timed out
The clock ran out before an answer was submitted.
Counted
The quiz marked the answer not right, and the student pressed Count mine as correct. Usually a synonym or a spelling the quiz does not know, which is worth checking against that structure's accepted names.
% right
Right and Counted together, out of Answers: the way the quiz itself scores a run.

Only each answer's result is kept, never what was typed.

Each count is a small message from a page to Lambda's counter on Cloudflare, saying only what happened, such as "atlas, dorsal view" or "quiz answer, right". A page opened through an instructor's link also says which link, by its class name, which is the same for every student on it. Quiz answers are kept only as right, wrong, skipped, or timed out, never what was typed. No cookie, address, or identifier of a person is read or stored; the database holds totals for each day and the class names typed into the link builder. Before this counter started in October 2026, a service called GoatCounter counted page visits and quizzes, and its totals are carried into the numbers here. The code is in the repository.
